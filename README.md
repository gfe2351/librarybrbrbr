# National Library - ASP.NET Core MVC Project

Данный проект содержит реализацию веб-приложения библиотеки «National Library» на C# / ASP.NET Core MVC с выполнением всех 25 технических задач.

## Как запустить проект локально:

1. Распакуйте архив в любую удобную папку.
2. Откройте терминал (или командную строку / PowerShell) в папке `NationalLibraryApp`.
3. Выполните команду запуска:
   ```bash
   dotnet run
   ```
4. Откройте браузер и перейдите по адресу: `http://localhost:5000` (или `https://localhost:7001`).
